THAM KHẢO LARAVEL api → PYTHON fast (common layer map)
================================================================================

Đọc ~/workspace/api/src/app/Http/* và api/docs — implement tương đương trên fast:

  Laravel / Nest (portal cũ)     Python fast (src/app/common/)
  --------------------------     ---------------------------
  BaseController + ApiResponse   common/http/api_response.py + exception_handlers
  EntrySearchTrait               services/mixins/search_mixin.py hoặc BaseReadService
  EntryCreate/Update Trait       services/commands/* (CQRS-lite folder)
  BaseAction / BaseWriteHandler  common/services/base_write_service.py (ABC)
  BaseQuery + BaseCriteria       common/services/base_read_service.py + criteria.py
  BaseResource                   common/presenters/base.py (to_contract)
  FormRequest                    modules/*/schemas/request.py (Pydantic)
  BasePolicy                     common/auth/policies.py + Depends()
  BaseMiddleware               Starlette middleware / dependencies
  SelectItemTrait                common/services/select_item.py
  Pagination helper              common/pagination.py
  Module Routes/api.php          modules/*/router.py → include main.py

Pattern đã chốt cho fast:
  - Router mỏng (như Controller)
  - Service layer (KHÔNG CommandBus ceremony)
  - Presenter transform entity → contract keys (portal-contract-naming)
  - Pydantic response + envelope { success, data, message }
  - ABC + Mixin + Protocol thay PHP trait
