# /update-spec — Controlled spec delta

**Extracts:** `extractBundle: update-spec` → `.cursor/extracts/extract-registry.json`

Doc hub: `docs/operational/UPDATE-SPEC-FLOW.md` · `docs/operational/FEATURE-ARTIFACT-FLOWS.md`

## Load policy

| Load | Do not load |
|------|-------------|
| `docs/features/yaml/.../{function}/*.bundle.yaml` — **SSOT** patch target | `ir/*.yaml` — regenerated by split |
| `docs/features/yaml/.../{function}/*.test.yaml` — E2E testcase deltas | Legacy source, codegen manifests |
| `spec-update-delta.md` matrix | Full bundle rewrite |

## Scope

**In:** patch bundle (+ testcase when E2E scope changes); `pnpm spec:split`; emit `#update:*`; bump `specRevision`.

**Out:** full rewrite (`/spec`), legacy re-mine (`/update-spec-legacy`), production code, direct `ir/` edits.

## Workflow

1. Identify delta scope (one scenario / block / API field).
2. Patch minimal YAML sections in **bundle** per `spec-update-delta.md` (not `ir/*`).
3. Emit matching `#update:*` tags; bump `specRevision`.
4. If `featureStatus` was `wire` → `need-update`.
5. Record harness notes when present.
6. `pnpm spec:split -- docs/features/yaml/.../{function}/{id}.bundle.yaml`
7. `pnpm spec:split:check -- docs/features/yaml/.../{function}/{id}.bundle.yaml`
8. User runs `pnpm docs:render` (manual).
9. Follow-up per matrix: `portal:gen [--force]`, `/bqa-grill-docs`, `/dev-grill-docs`, `/test`, or `/wire`.

## Path examples

```text
docs/features/yaml/admin/hotel/list/hotel-list.bundle.yaml   # patch here
docs/features/yaml/admin/hotel/list/hotel-list.test.yaml       # E2E delta
docs/features/yaml/admin/hotel/list/ir/spec.yaml               # read-only — from split
```

## Guardrails

- Do not strip legacy evidence or unrelated blocks.
- Do not add `codegen` / `gen:` without Dev alignment — hand off `/dev-grill-docs`.
- Tags cleared only at `/wire` — not during this command.

## Done

- Delta documented in bundle + tags; `ir/*` regenerated and split:check pass.
- Next command obvious from patch type.
